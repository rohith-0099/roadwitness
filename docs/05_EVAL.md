# 05 — Evaluation (scored: technical execution, agentic task effectiveness, docs)

Principle (lesson from past winners): **grade ourselves with numbers we earned, and show where we fail.** Never tune on the test split. Never report a metric we didn't compute.

## Datasets (`eval/datasets.md` records source, license, size, split)
- **Local set** (own captures): ≥300 labeled frames, held-out test split by *road*, not by frame.
- **Re-ID pairs**: ≥30 same-pothole pairs (different angle/phone/day) + ≥30 different-pothole hard negatives nearby.
- **Repair pairs**: before/after of potholes that got repaired, still open, or poorly patched (collect as many as real life allows; label honestly; small N is fine if stated).
- **Trap set**: puddles, shadows, manhole covers, speed breakers, patched asphalt, cracks, wet roads, night/low light, motion blur, glare.
- Public datasets only with a compatible license.

## Metrics
| Component | Metric |
|---|---|
| Quality gate | % bad frames correctly rejected; % good frames wrongly rejected |
| Detector/segmenter | precision, recall, mask IoU on local test; **false-positive rate on trap set** |
| VLM second opinion | change in precision/recall when enabled vs disabled; latency per call; % of detections that needed it |
| Measurement | area error vs hand measurement with ArUco (n small, stated) |
| Re-ID / dedupe | precision/recall of "same pothole"; dedupe ratio on real ride data |
| Repair verification | confusion matrix FIXED/NOT_FIXED/POOR_PATCH/CANT_TELL |
| Agent (scenario suite) | % scenarios with correct decision; # human interventions; re-shoot success rate; failure handling cases |
| System | p50/p95 latency per report, cost per report on Graviton; throughput |
| COOL (stretch) | latency/throughput/cost: COOL ARM64 vs stock ARM64 vs x86, same inputs, ≥5 runs, report variance |

## Failure cases to document (with images)
Night, heavy rain, water-filled pothole, occluded by vehicle, very shallow defects, GPS drift merging two nearby potholes, VLM disagreeing wrongly. For each: what the system does (re-shoot? CANT_TELL? officer flag?) — failing safely is a feature.

## Responsible-use checks
- Blur coverage: % of faces/plates in a sample that were blurred (manual audit, stated N).
- Raw video retention period and deletion job verified.
- No identity/vehicle tracking features exist.
- Every external send has an approval record.

## Outputs
`eval/results/*.md` + plots, regenerated by `python -m eval.run_all`. The report quotes these files, not memory.
